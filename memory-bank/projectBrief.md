# Project Brief

PC Lock Control is a web application designed to remotely manage and control Windows PCs via a locked-down kiosk application. It allows users to lock/unlock PCs, view status, and manage usage schedules.

## Core Features
- **Dashboard**: View all configured PCs and their connection status.
- **Remote Control**: Lock and unlock PCs instantly.
- **Scheduling**: Configure automated lock/unlock schedules (e.g., daily 22:00 - 07:00).
- **Management**: Add, edit, and remove PCs from the control panel.
- **Secure Connection**: Communicates with a companion Windows app via a secure API with password authentication.

## Goals
- Provide a simple, mobile-friendly interface for parents or admins to control PC access.
- Ensure reliability in lock enforcement.
- Maintain a persistent record of configured PCs and their schedules.
